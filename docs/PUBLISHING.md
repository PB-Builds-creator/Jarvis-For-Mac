# Publishing checklist

The local repository is prepared for GitHub Desktop. Publish only after `./scripts/verify.sh` passes and `git status` is clean.

## GitHub Desktop

1. Open **GitHub Desktop** and confirm you are signed in as `PB-Builds-creator`.
2. In the macOS menu bar, click **File → Add Local Repository…**.
3. Click **Choose…**.
4. Select the local `Jarvis For Mac` repository folder.
5. Click **Add Repository**.
6. Confirm the top repository selector says `Jarvis For Mac` and the current branch says `main`.
7. Click **Publish repository** in the top bar.
8. Set **Name** to `Jarvis-For-Mac`.
9. Paste this description: `Local-first macOS AI agent with on-device voice, tiered model routing, structured memory, owner verification, and confirmation-gated computer control.`
10. Leave **Organization** as **None**.
11. **Uncheck** `Keep this code private`.
12. Click **Publish Repository** once.
13. When it completes, use **Repository → View on GitHub**.

Do not create a second empty repository first. Do not upload anything from `~/Jarvis/Data`, `~/Jarvis/Information`, `~/Jarvis/Models`, or the private source installation.

## Repository page

1. Beside **About**, click the gear icon.
2. Keep the same description.
3. Add topics: `macos`, `swift`, `python`, `local-ai`, `ai-agent`, `mlx`, `coreml`, `speech-recognition`, `app-intents`, `sqlite`, `computer-use`, `privacy`.
4. Enable **Issues** and **Discussions** only if you intend to monitor them.
5. Open your GitHub profile, choose **Customize your pins**, and pin `Jarvis-For-Mac` first.
6. Do not create a binary Release yet. The repository documents that Developer ID signing and notarization are still required.

## LinkedIn

1. Open **Me → View Profile → Add profile section → Recommended → Projects**.
2. Use the project name, description, skills, and repository link from `docs/PORTFOLIO_COPY.md`.
3. If LinkedIn does not show a Project URL field, click **Add media → Add a link** and paste the repository URL.
4. Add the project under the accurate **PB Builds / Self-employed AI Application Developer** experience entry; do not invent employment or client claims.
5. Publish the launch post provided in the final handoff, then add the post or repository link to **Featured** if your LinkedIn plan exposes that section. If it does not, the Projects entry, Experience media, and public post are sufficient.
